# 课程模板

维护者新增课程时应复制源文件结构，不要直接在生成的 `site/` 目录修改。

```markdown
---
title: 07 · 课程名称
description: 一句话说明课程产出
---

# 07 · 课程名称

<div class="lesson-progress"
     data-lesson-id="unique-lesson-id"
     data-lesson-title="课程名称"></div>

## 学习目标

- 使用可验证的动词描述目标。

## 先修知识与硬件

列出课程、板卡、仪器和实际引脚要求。

## 核心概念

解释为什么这样做，而不只给出配置截图。

## 配置与实现

所有代码说明插入位置、依赖的句柄和硬件极性。

## 验收方法

- [ ] 正常路径可复现。
- [ ] 至少一个错误场景可观察、可定位。

## 常见问题

给出按层排查顺序。

## 练习与下一步

练习应要求修改、测量或解释，而不是机械复制。
```

## 编写检查表

- 标题、导航序号和 `data-lesson-id` 唯一。
- 示例不假设所有板卡引脚一致，明确硬件依赖。
- HAL/API 调用说明错误返回值和阻塞行为。
- 时间比较考虑系统节拍回绕。
- 中断示例避免延时和阻塞 I/O。
- 外部资料链接到官方入口，并记录核验日期。
- 课程能在目标板上完成验收，或明确标注尚未实测。
