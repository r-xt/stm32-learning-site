# 专家路线

## 阶段目标

设计可长期运行、可诊断、可升级的嵌入式系统，而不只是增加更多外设。

## 核心主题

- FreeRTOS 任务、队列、通知、互斥和优先级设计
- 中断到任务的数据通路与实时性分析
- Stop/Standby、唤醒源和实际功耗测量
- 链接脚本、栈/堆、Cache 与 MPU
- Bootloader、镜像布局、校验、回滚和断电恢复
- HardFault 分析、看门狗、崩溃记录和现场日志
- 单元测试、静态分析与可重复构建

## 阶段项目

实现一个低功耗数据采集终端：具备任务化采集、通信、持久化日志、看门狗恢复和双镜像升级。用故障注入验证断电、损坏镜像、通信中断与传感器失联场景。

## 退出标准

你能够用时序、内存和故障模型解释架构选择，并为升级失败、资源耗尽和现场诊断提供明确方案。
