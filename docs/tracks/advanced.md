# 进阶路线

## 阶段目标

从“调用 HAL”进阶到“理解数据如何在外设、DMA、内存和驱动之间流动”，能够用仪器和寄存器定位时序问题。

## 推荐顺序

1. 时钟树、NVIC、启动流程与内存映射
2. [ADC + DMA 连续采样](../courses/adc-dma.md)
3. [I²C 传感器通信](../courses/i2c.md)
4. [SPI 与外部器件](../courses/spi.md)
5. RTC、看门狗、内部 Flash 和故障记录
6. CAN/USB 等至少一种复杂通信
7. HAL、LL 与寄存器实现对比
8. 驱动接口、状态机、超时和错误恢复

## 阶段项目

构建一个[多外设数据记录器](../projects/data-logger.md)：定时采样传感器，使用 DMA 搬运数据，通过 UART 输出日志，并将关键配置写入非易失存储。至少处理一次总线超时、传感器离线和缓冲区溢出。

## 退出标准

- 能从逻辑分析仪波形解释 I²C/SPI 一次事务。
- 能说明 DMA 缓冲区所有权以及何时可以读写。
- 能区分“设备没响应”“协议解析错误”和“业务数据异常”。
- 能在不修改 HAL 源码的前提下封装可测试驱动。
